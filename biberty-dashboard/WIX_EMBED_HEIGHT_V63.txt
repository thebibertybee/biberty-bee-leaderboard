BIBERTY ANALYTICS V63 — WIX EMBED HEIGHT

What is possible:
- The normal Wix Editor "Embed a Site" / HTML iframe element has an editor-set height. It DOES NOT automatically expand to fit the GitHub Pages dashboard. Changing CSS on the dashboard cannot change this outer Wix height.
- Version 63 now sends its measured content height using parent.postMessage whenever the data, section, report, or layout changes. This is groundwork for an embedding host that supports dynamic resizing.

RIGHT NOW — for your current normal Wix embed:
1. Replace your GitHub Pages dashboard files with the V63 folder.
2. In Wix Editor, select the embedded site box and drag its bottom edge down until the dashboard has no inner scrollbar for the longest view you expect to use.
3. Check mobile separately in the Wix mobile editor; it has a different width/height and may need a different box height.
4. The tradeoff is blank space on short sections. There is no reliable automatic height for this standard Wix element.
5. Version 63 also shows a discreet "Open full dashboard" link when inside an iframe, which is the zero-second-scroll option on any Wix plan.

OPTIONAL ADVANCED ROUTE — if you upgrade Wix and connect a domain:
Wix Custom Elements can change their height on published sites. Wix's help center says they require a Premium plan, a connected domain, and removal of Wix ads.
We've included an OPTIONAL experimental custom-element file, wix-autoheight-element.js, that listens for the dashboard's height message and resizes the iframe and its custom-element host:
- Add Elements > Embed Code > Custom Element > Server URL
- Server URL: https://thebibertybee.github.io/biberty-bee-leaderboard/biberty-dashboard/wix-autoheight-element.js
- Tag Name: biberty-analytics-embed
- Make the element full width and ensure its section can grow. Test the PUBLISHED site, since Wix renders custom elements differently in the editor.
This may still be restricted by the outer Wix editor layout and is not guaranteed to eliminate Wix's scrollbar. Do not remove your working embed until tested.

Dashboard message:
{type:'biberty-dashboard:height',source:'biberty-analytics',version:1,height:<content pixel height>}
