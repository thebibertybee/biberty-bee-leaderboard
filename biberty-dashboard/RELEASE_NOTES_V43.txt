The Biberty Bee Analytics — Version 43
Data accuracy, comparison reports, and visualization overhaul

WHAT CHANGED
- Post Snapshots is now the canonical source for like/comment comparisons, post leaderboards, and report charts. Repeated snapshots are consolidated by account + post ID. Newer blank likes/comments cannot overwrite an earlier available number.
- All 30-day account performance figures use one explicitly dated window. The new Data Check indicator displays the number of unique posts and flags disagreements with Muse's Account Post Stats summary feed.
- Missing, hidden, unavailable, or failed post counters are not treated as zero; valid zero comments remain zero.
- Instagram user IDs in Accounts are used for matching when provided, with username/name fallbacks.
- Engagement and Like Rate rankings prioritize Complete-coverage accounts with >=5 eligible posts; smaller samples remain visible and flagged.
- Top Posts still supports overall and one per account, using the complete available Post Snapshots history and the selected date period.
- Detailed comparison reports distinguish audience size from relative follower growth and post performance. Followers are compared over a common observed period only when each account has nearby recorded start/end readings; otherwise the report explicitly declines to rank growth head-to-head.
- Detailed reports now have an aligned follower comparison table, an audience-adjusted Like Rate bar chart, per-account post metrics, sample sizes, median likes, post timelines, and chart explanations.
- Selected academic-year reporting periods consistently control post metrics throughout the report. Old posts' likes/comments are labeled as the latest recorded counters, NOT interactions received during that historical school year.
- The main Compare page now includes a separate, explicitly dated post-performance comparison for two accounts.
- Mobile navigation wraps without spilling off-screen. Wide data tables scroll only within their table containers. Detailed report tables fit page width in test PDF.
- Original classic Georgia report title and original navy gradient remain; no Playfair Display assets are included.

FACTS AND LIMITATIONS
- Like Rate is average visible likes per post divided by CURRENT followers; it is not a like-to-view rate, and it cannot reconstruct historical follower counts.
- Estimated interaction rate similarly uses separately averaged visible likes and comments. Missing metrics are excluded, which means the denominators may differ.
- The follower series and post series can start and end on different dates. This report does not interpolate missing follower readings or make claims of synchronized growth when the accounts' tracking windows don't overlap.
- Post history may still be incomplete as the historical backfill progresses. Complete/Partial/Failed is sourced from the latest Account Post Stats feed, which covers its latest 30-day window; it does not certify every past school year.
- Public post counters can change between collections and can include interactions from nonfollowers. The site does not have access to Instagram Insights, impression counts or viewer counts.
- Direct access to the live public Google Sheets CSV was blocked in this development environment. The code was tested in headless Chromium using representative CSV fixtures with the exact headers provided by Muse, including duplicate snapshots, missing likes, uneven follower histories, and cross-account comparisons. Do a published-site smoke check before promoting to visitors.

INSTALL
Unzip and drag the enclosed biberty-dashboard folder's files into your GitHub repository's biberty-dashboard path, replacing matching files. Keep this directory name to preserve the Wix embed URL.
No changes to Muse's collection jobs or Google Sheets are needed.
